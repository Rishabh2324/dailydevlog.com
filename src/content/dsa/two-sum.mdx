## Problem

Given an array of integers `nums` and an integer `target`, return the indices of the two numbers that add up to `target`.

## Approach

A brute-force scan checks every pair, which costs `O(n^2)`. Instead, walk the array once and keep a hash map of
`value -> index` for numbers already seen. For each number, check whether `target - number` is already in the map —
if it is, the pair is found.

## Solution

```ts
function twoSum(nums: number[], target: number): number[] {
  const seen = new Map<number, number>();

  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i];
    if (seen.has(complement)) {
      return [seen.get(complement)!, i];
    }
    seen.set(nums[i], i);
  }

  return [];
}
```

## Complexity

- **Time:** `O(n)` — a single pass over the array.
- **Space:** `O(n)` — the hash map can hold up to `n` entries.
