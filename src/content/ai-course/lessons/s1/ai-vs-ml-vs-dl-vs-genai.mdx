## Why this matters

People use "AI", "machine learning", "deep learning" and "GenAI" as if they mean the same thing. They don't. Knowing
the difference helps you understand product announcements, job posts and what a tool can actually do.

By the end of this lesson, you'll be able to explain how the four terms fit together in two sentences.

## The idea

The four terms are nested, like boxes inside boxes:

- **Artificial intelligence (AI)** is the big goal: computers doing tasks that seem to need human intelligence.
- **Machine learning (ML)** is one way to reach that goal. Instead of writing every rule, you show the computer
  examples and it learns the pattern.
- **Deep learning (DL)** is a kind of machine learning that uses large neural networks with many layers.
- **Generative AI (GenAI)** is deep learning used to create new things: text, images, audio or code.

Every GenAI system is deep learning. Every deep learning system is machine learning. But not all AI learns from
data.

```text
┌──────────────────────────────────────────┐
│ AI: computers doing "smart" tasks        │
│  ┌────────────────────────────────────┐  │
│  │ ML: learns patterns from examples  │  │
│  │  ┌──────────────────────────────┐  │  │
│  │  │ DL: large neural networks    │  │  │
│  │  │  ┌────────────────────────┐  │  │  │
│  │  │  │ GenAI: creates content │  │  │  │
│  │  │  └────────────────────────┘  │  │  │
│  │  └──────────────────────────────┘  │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

This nested-circles picture was made popular by the *Deep Learning* textbook (Goodfellow, Bengio & Courville,
2016). We added the GenAI layer.

## A real-life example

Think about how different apps on your phone are "smart":

- **A chess app from the 1990s** is AI, but not machine learning. Programmers wrote the rules for searching moves.
- **Your email spam filter** is machine learning. It learned what spam looks like from millions of emails people
  marked as spam.
- **Face unlock on your phone** is deep learning. A neural network learned to recognize faces from images.
- **ChatGPT, Claude or Gemini writing an email for you** is generative AI. A very large neural network creates new
  text word by word.

All four are "AI". Only the last three learned from data, and only the last one creates something new.

## How it works

1. **Rule-based AI** follows instructions a person wrote: "if the email contains 'free money', mark it as spam".
2. **Machine learning** looks at many labeled examples and finds the pattern by itself. You give it data and the
   right answers, and it produces the rules.
3. **Deep learning** does the same with neural networks: many layers of simple math units. The layers let it learn
   from messy data like pixels, sound and text, where writing features by hand is too hard.
4. **Generative AI** trains huge deep learning models to predict what comes next, such as the next word. Repeating
   that prediction lets them write whole answers, or build whole images.

## Where you'll see it

- Product pages say "AI-powered" for almost anything. Ask which kind it is: rules, classic ML or GenAI.
- Job titles differ: an "ML engineer" often trains models; an "AI engineer" usually builds products on top of
  existing GenAI models.
- LLMs (large language models) like GPT, Claude, Gemini and Llama are GenAI. You'll meet them in lesson 1.4.1.
- Many real systems mix types: a support tool might use rules for routing, ML for spam, and GenAI for replies.

## Common confusions

- **AI is not only chatbots.** Recommendation systems, fraud detection and route planning are AI too.
- **Machine learning is not always deep learning.** Many useful models are small and simple, like a spam filter.
- **GenAI is not "thinking" like a person.** It predicts likely output based on patterns in its training data.

<Callout type="note">
  The terms are used loosely in the industry. When someone says "AI" in 2026, they usually mean generative AI.
</Callout>

## Key terms

| Term | Meaning |
|---|---|
| AI | Computers doing tasks that seem to need intelligence |
| Machine learning | Learning patterns from examples instead of hand-written rules |
| Deep learning | Machine learning with large, many-layered neural networks |
| Generative AI | Models that create new text, images, audio or code |
| Neural network | A model made of layers of simple math units (lesson 1.1.4) |
