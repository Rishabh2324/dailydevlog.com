## Why this matters

AI news is full of GPUs: companies buying tens of thousands of them, chip shortages, "GPU hours". When you run a
model yourself, the first question is whether it fits on your GPU. Knowing why AI needs this hardware helps you
understand costs, speed and model choices.

By the end of this lesson, you'll be able to explain why AI runs on GPUs and why GPU memory matters so much.

## The idea

A neural network is mostly one kind of work repeated billions of times: **multiplying big tables of numbers**
(matrices) together. Each multiplication is simple, and most of them don't depend on each other, so they can all
happen **at the same time**.

- A **CPU** has a few very powerful cores. It's great at complex tasks done one after another.
- A **GPU** has thousands of simpler cores. It's great at doing the same simple task on lots of data at once.

Neural network math is exactly the kind of work GPUs are good at. GPUs were built for graphics, which is also lots
of simple math on many pixels at once.

## A real-life example

A common way to picture it: imagine you need to **chop 10,000 onions**.

- A CPU is like **4 world-class chefs**. Each is fast and can cook anything, but there are only 4 of them.
- A GPU is like **2,000 kitchen helpers**. Each can only do simple chopping, but they all chop at once.

For 10,000 onions, the 2,000 helpers win easily. For inventing a new recipe, you want the chefs. Training and
running neural networks is mostly onion chopping.

Now the second part: the helpers need **onions delivered to their tables**. If the delivery is slow, it doesn't
matter how fast they chop. For LLMs, the "delivery" is moving the model's weights in and out of memory, and it's
often the real bottleneck.

## How it works

1. **Everything is numbers in matrices.** Inputs, weights and outputs are big grids of numbers (lesson 1.1.5).
2. **Each layer multiplies matrices.** A big model does this for billions of weights on every step.
3. **GPUs run those multiplications in parallel**, often tens or hundreds of times faster than a CPU for this work.
4. **The model must fit in GPU memory.** A 7B model at 16-bit needs about 14 GB (lesson 1.1.5). A data center GPU
   like NVIDIA's A100 comes with 40 or 80 GB (NVIDIA). A typical laptop GPU has much less.
5. **Memory speed limits LLM answers.** To write each word, an LLM reads through all its weights. So how fast the
   GPU can move data from memory often decides how many words per second you get.
6. **Big models use many GPUs.** Training spreads the work over thousands of GPUs connected by fast links.

## Where you'll see it

- **"GPU hours"** measure training cost: one GPU running for one hour.
- **Cloud pricing** for GPUs is per hour, and the biggest GPUs are the most expensive.
- **Running models locally** depends on your GPU's memory; Apple's M-series chips share memory between CPU and GPU,
  which helps fit larger models.
- **Tokens per second** is the speed number you'll see for inference.
- **Other AI chips** exist too, like Google's TPUs, with the same basic idea: lots of parallel math.

## Common confusions

- **A faster GPU doesn't always mean faster answers.** If memory is the bottleneck, more memory speed helps more
  than more cores.
- **You don't need a GPU to use AI.** Calling a model through an API runs on the provider's GPUs.
- **Training and inference need different amounts.** Training needs far more memory and GPUs than running the same
  model (lesson 1.1.9).

## Key terms

| Term | Meaning |
|---|---|
| GPU | A chip with thousands of simple cores for parallel math |
| Matrix multiplication | The core math operation inside neural networks |
| GPU memory (VRAM) | The GPU's own fast memory, where the model must fit |
| Memory bandwidth | How fast data moves in and out of that memory |
| GPU hours | Number of GPUs times hours used, a measure of compute cost |
