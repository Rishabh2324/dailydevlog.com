## Why this matters

Almost every modern AI system, from face unlock to ChatGPT, is a neural network. The terms "neuron", "layer" and
"activation" show up in model docs and AI news constantly.

By the end of this lesson, you'll be able to describe what a neural network is made of in plain words.

## The idea

A **neural network** is a function built from many small, simple pieces called **neurons**, arranged in
**layers**.

Each neuron does one tiny job:

1. It takes some numbers in.
2. It multiplies each number by a **weight** (how important that input is) and adds them up.
3. It passes the total through an **activation**, a simple rule that decides how strongly the neuron "fires".

One neuron is almost useless. Thousands or billions of them, in many layers, can recognize faces or write text.

## A real-life example

Think of a **hiring panel** deciding whether to invite a candidate for an interview.

- The first reviewers each look at a few details: one checks experience, one checks skills, one checks the cover
  letter. Each gives a score, and some details matter more to them than others. Those are neurons with weights.
- A second group reads the first group's scores and forms bigger opinions, like "strong engineer" or "good
  communicator". That's a hidden layer building on the one before.
- A final person combines those opinions into one decision: invite or not. That's the output layer.

No single reviewer decides alone. The decision comes from many simple judgments combined. Neural networks work the
same way.

A real case: **handwritten digit recognition**, the classic example in 3Blue1Brown's video. Early layers notice
small strokes and edges. Later layers combine them into loops and lines, and the last layer says "this is a 7".

## How it works

1. **Input layer.** The data goes in as numbers: pixel brightness, or numbers standing for words.
2. **Hidden layers.** Each layer's neurons combine the previous layer's outputs. Early layers find simple patterns;
   later layers find combinations of those patterns.
3. **Activations.** Without them, stacking layers would be pointless: the whole network would behave like one
   simple layer. Activations like **ReLU** ("if negative, output zero") let the network learn curves and complex
   shapes.
4. **Output layer.** The final numbers are the answer, such as a score for each possible label.
5. **Learning.** At first the weights are random, so the answers are nonsense. Training adjusts the weights until
   the answers are good (lessons 1.1.6 to 1.1.8).

"Deep" learning just means the network has many layers.

## Where you'll see it

- **Model sizes** like "8B" count the weights inside a neural network (lesson 1.1.5).
- **"Layers"** appear in model descriptions, for example "32 layers".
- **ReLU, GELU and softmax** are activation names you'll see in model docs. Softmax turns scores into
  probabilities that add up to 1.
- **Transformers**, the architecture behind LLMs, are a kind of neural network (lesson 1.3.1).

## Common confusions

- **Artificial neurons are not brain cells.** The name was inspired by the brain, but they are just small math
  functions.
- **Nobody programs what each neuron does.** The network learns it during training, and it's often hard to explain
  afterwards.
- **More layers isn't always better.** Bigger networks need more data and compute, and can memorize instead of
  learn (lesson 1.1.10).

## Key terms

| Term | Meaning |
|---|---|
| Neuron | A unit that adds weighted inputs and applies an activation |
| Layer | A group of neurons that work at the same step |
| Hidden layer | Any layer between the input and the output |
| Activation | A simple rule that shapes a neuron's output, like ReLU |
| Deep network | A neural network with many layers |
