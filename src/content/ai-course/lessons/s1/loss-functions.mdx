## Why this matters

A model can't improve unless something tells it how wrong it is. That something is the loss function. You'll see
"loss going down" in every training chart, and the idea explains why LLMs are so good at predicting text.

By the end of this lesson, you'll know what a loss function is and why training is all about making it smaller.

## The idea

A **loss function** takes the model's answer and the correct answer, and returns one number: **how wrong** the
model was.

- Loss of 0 means perfect.
- A bigger loss means more wrong.

**Training** means changing the model's parameters to make the loss as small as possible across all the training
examples.

## A real-life example

Think of **learning to throw darts**. After every throw, you see how far the dart landed from the bullseye. That
distance is your loss. You adjust your aim to make it smaller next time. You don't need anyone to tell you exactly
how to move your arm, only how far off you were.

Another everyday case: a **weather app** says 30°C, and it turns out to be 25°C. It was 5 degrees off. If the app's
model is trained on many days, the loss adds up those misses, and training pushes the total down.

## How it works

1. **The model makes a guess** for a training example.
2. **The loss function compares** the guess with the right answer and gives a number.
3. **The losses are averaged** over many examples, so one lucky guess doesn't count too much.
4. **Training changes the parameters** to lower that average (lesson 1.1.7 shows how).
5. **The loss is watched over time.** A chart where the loss goes down means the model is learning.

Different tasks use different loss functions:

- **Predicting a number** (a price, a temperature) often uses **mean squared error**: the size of the miss,
  squared, so big misses count a lot more than small ones.
- **Picking a category** (spam or not, which word comes next) uses **cross-entropy**. It punishes being confidently
  wrong very hard. Saying "99% sure it's not spam" about a spam email costs far more than saying "60% sure".

## Where you'll see it

- **Training charts:** "training loss" and "validation loss" curves show whether a model is learning.
- **LLM training:** the loss is cross-entropy on the next word (more exactly, the next token). A low loss means
  the model is rarely surprised by real text.
- **Perplexity:** a number reported for language models that comes directly from this loss. Lower is better.
- **Fine-tuning tools** show loss while you train, so you can tell if something is going wrong.

## Common confusions

- **Loss is not accuracy.** Accuracy counts right answers. Loss also measures how confident and how far off the
  model was. A model can get more answers right and still have a worse loss.
- **Lower training loss isn't always good.** If loss on training data keeps falling but loss on new data rises, the
  model is memorizing (lesson 1.1.10).
- **You pick the loss function.** It defines what "wrong" means, so choosing it is a design decision.

## Key terms

| Term | Meaning |
|---|---|
| Loss function | A formula that scores how wrong a model's answer is |
| Loss | The resulting number; lower is better |
| Mean squared error | A loss for number predictions that punishes big misses |
| Cross-entropy | A loss for categories that punishes confident wrong answers |
| Perplexity | A language-model score based on cross-entropy loss |
