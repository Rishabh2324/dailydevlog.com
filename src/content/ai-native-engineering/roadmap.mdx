## Course philosophy

1. **AI augments engineering thinking; it doesn't replace it.** Every lesson asks: *how would a good software engineer use AI for this task?*
2. **Workflows, not tool tours.** Tools are labeled examples. The workflow is what lasts.
3. **Verify everything.** Anything AI generates is a draft until it has been tested and a human has decided.
4. **Know when not to use AI.** Every lesson says where AI hurts more than it helps.
5. **One running project.** Lessons build on the same product, so each skill connects to real work.

## The core loop

```
UNDERSTAND → DISCOVER → ANALYZE → PLAN → DESIGN → CONTEXTUALIZE
    → GENERATE → IMPLEMENT → VERIFY → TEST → REVIEW → SHIP
    → MONITOR → LEARN → IMPROVE → AUTOMATE
```

## The working model

```
Developer → Context → AI → Generated / suggested result
    → Verification → Testing → Human decision → Production
```

<Callout type="practice" title="Who this course is for">
